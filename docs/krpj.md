# Kratience Project Format (KRPJ)
A Kratience project is a `.krpj` file: a zip archive holding `game.json` at its root plus the project's own assets at their `./` paths. The editor saves and opens `.krpj` files, gm2kr exports them, and Kressel (krplayer) plays them.

```
coin-collector.krpj
├── game.json            main project file (text/json, described below)
├── sprites/<key>/<frame>.png
└── fonts/<key>.png
```

`game.json` is generated by the editor and interpreted by the engine. The editor works somewhat like Scratch/TurboWarp does, and the (interpreted) scripting blocks in `game.json` reflect the codeblocks as they appear in the editor.

All non-text resources are external files not in `game.json`, either as assets in the project (./asset.ext, stored next to `game.json` in the `.krpj` or on the CDN) or shared assets (/sa/~someone/asset.ext). (e.g. images, audio)

This is to allow expensive per-room assets to be loaded in during room transitions, among other advancements.

`game.json` is not a one-to-one data.win-to-JSON representation, it is its own format built to be interpreted in a web player. Where the ease & speed of the Kratience engine & editor benefits, changes will be made from GameMaker's setup (for example, the use of individual textures over texture maps).

## Example Small Project Structure (game.json)
```jsonc
{
    "krpj_v": "0.1", // kratience version. stuck at 0.1 for now
    "cfg_db_relay": { // for double checking information about the project from the DB
        "slug": "coin-collector",
        "title": "Coin Collector",
        "author": "admin",
        "revision": 1,
        "date_created": 1793770552, // timestamp(z)
        "date_updated": 1793770552,
    },
    "cfg_gm_compat": {
        "imported_from": null,
        // if imported from a gamemaker project, has some info about the origin
    },
    "cfg_defaults": { // can be changed via game scripting
        "width": "default",
        "height": "default",
        "fps": 60,
        "window_title": "Coin Collector",
    },
    "cfg_project": { // can't be changed via game scripting
        "init_room": "room_main"
    },
  "sprites": {
    "spr_VleMv5v8Og": {
      "name": "player",
      "frames": ["./sprites/spr_player/0.png", "./sprites/spr_player/1.png"],
      "origin": [16, 16],
      "speed": 8
    },
    "spr_J3qvFn5sTQ": {
      "name": "coin",
      "frames": ["/sa/~admin/coin.png"],
      "origin": [8, 8],
      "speed": 0
    }
  },
  "sounds": {
    "snd_DkIcBl5DhB": { "name": "coin", "src": "/sa/~admin/snd_coin.ogg", "volume": 0.8, "stream": false }
  },
  "fonts": {
    "fnt_G785KWucVA": { // fonts are the exception to individual textures: pre-rendered to an atlas, like GameMaker
      "name": "main",
      "atlas": "./fonts/fnt_main.png", // glyph texture page
      "font_name": "Arial", // source font, used by the editor to regenerate the atlas
      "size": 16,
      "bold": false,
      "italic": false,
      "antialias": 1,
      "line_height": 19,
      "ranges": [[32, 127]],
      "glyphs": { // char code: [x, y, w, h, shift, offset]
        "32": [2, 2, 4, 19, 4, 0],
        "48": [8, 2, 9, 19, 9, 0],
        "83": [19, 2, 11, 19, 11, 0]

      "args": ["amount"],

        ["var_set", ["_iv", ["_kw", "global"], "score"],

    }
  },

    "obj_player": {
      "sprite": "spr_VleMv5v8Og",
      "parent": null,
      "visible": true,
      "persistent": false,
      "scripts": [
        ["evt_create", [
          ["var_set", ["_lv", "move_speed"], 4],
          ["var_set", ["_iv", ["_kw", "global"], "score"], 0]
        ]],
        ["evt_step", [
          ["ctr_if", ["sen_key_held", 39], [
            ["var_set", ["_lv", "x"], ["opr_add", ["_lv", "x"], ["_lv", "move_speed"]]]
          ]],
          ["ctr_if", ["sen_key_held", 37], [
            ["var_set", ["_lv", "x"], ["opr_sub", ["_lv", "x"], ["_lv", "move_speed"]]]
          ]]
        ]],
        ["evt_drawgui", [
          ["drw_set_font", ["_as", "fnt_G785KWucVA"]],
          ["drw_text", 8, 8,
            ["opr_add", "Score: ", ["opr_string", ["_iv", ["_kw", "global"], "score"]]]]
        ]]
      ]
    },
    "obj_coin": {
      "imported_from": "/so/~admin/free-coin-object.krso", // indicates this was imported from a shared object
      "sprite": "spr_J3qvFn5sTQ",
      "parent": null,
      "visible": true,
      "persistent": false,
      "scripts": [
        ["evt_collision", ["_as", "obj_player"], [
          ["fnc_g", "fnc_giAqiCrTp2", 10],

          ["ins_destroy"]
        ]]

  },
  "rooms": {
    "room_main": {
      "width": 640,
      "height": 360,
      "preload": ["spr_VleMv5v8Og", "spr_J3qvFn5sTQ", "snd_DkIcBl5DhB", "fnt_G785KWucVA"],
      "layers": [
        {
          "name": "Background",
          "type": "background",
          "depth": 100,
          "color": 3355443,
          "sprite": null

          "name": "Instances",

          "depth": 0,

            { "object": "obj_coin", "x": 120, "y": 300 },
            { "object": "obj_coin", "x": 520, "y": 300 }

}
```

Roughly equivalent GML for `obj_player`'s step event:
```gml
if (keyboard_check(vk_right)) x = x + move_speed;
if (keyboard_check(vk_left))  x = x - move_speed;
```

## Field reference
Fields beyond the example above. All are optional unless noted; the types live in `krplayer/src/krpj.ts`.

* `cfg_gm_compat.imported_from`: `null`, or `{ "tool": "gm2kr", "game": <GM project name>, "bytecode": <15-17>, "gm_version": [major, minor, release, build] }`.
* `cfg_defaults.width` / `height`: `"default"` means the size of `init_room`.
* `room_order`: room keys in game order (`room_goto_next` etc.). Defaults to the key order of `rooms`.
* Asset keys (`sprites`, `fonts`, `objects`, `rooms`...) share one namespace, since `["_as", name]` names any of them. gm2kr uses the GameMaker asset names as keys.

**Sprites**
* `speed`: frames per second; with `"speed_type": "frame"`, frames per game frame instead.
* `bbox`: collision box `[left, top, right, bottom]` in inclusive image pixels. Defaults to the whole image.
* `mask`: `"rect"` (default; collides as the axis-aligned box around the scaled/rotated box), `"rotated"` (the rotated box itself) or `"precise"` (per-pixel; krplayer currently treats it as `"rotated"`).
* Frames are full, untrimmed images; `origin` is relative to their top-left.

**Fonts**: `size`, `bold`, `italic`, `antialias`, `line_height`, `ranges` and `glyphs` (`"code": [x, y, w, h, shift, offset]` in the atlas) as in the example; `kerning` is optional.

**Objects**
* `solid` (default `false`), `mask`: sprite key of a collision mask that differs from `sprite`.
* `scripts`: event hats (see krpj_opcodes.md). An object without an event uses its parent's.

**Rooms**
* `persistent` (default `false`).
* `scripts`: only `evt_create` (room creation code), run after every instance's create event and creation code.
* Layers: `visible` (default `true`) on every layer. Background layers also take `htiled`, `vtiled`, `stretch`; `color` is BGR.
* Instance entries: `object`, `x`, `y`, plus optional `scale_x`, `scale_y`, `angle`, `colour` (BGR), `alpha`, `image_index`, `image_speed` and `creation` (a script run right after that instance's create event).
* Instances are created layer by layer, in list order, each running its create event (then creation code) before the next is created.

## Loading projects
krplayer takes a project as a `.krpj` archive (opened by the user, or fetched from a URL), as an unpacked `game.json` URL whose `./` assets sit next to it (e.g. on the CDN), or as the same set of files handed over in memory by gm2kr (see architecture.md). A URL is treated as a `.krpj` when its content starts with the zip signature `PK`, otherwise as `game.json`.
